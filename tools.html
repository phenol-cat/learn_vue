HTML 常用标签用法大全

也就是你写网页时的“积木块”

1. 文本修饰 (你的划掉效果在这里)

这些标签用来改变文字的样子，就像 Word 里的加粗、斜体。

<b>加粗文字</b> 或 <strong>强调加粗</strong>
<i>斜体文字</i> 或 <em>强调斜体</em>
<u>下划线</u>
<s>删除线(划掉)</s>
<mark>荧光笔高亮</mark>
这是 普通加粗(b) 和 语义强调加粗(strong)
这是 普通斜体(i) 和 语义强调斜体(em)
这是 下划线(u)
这是 兽耳娘控(s) （已划掉）
这是 荧光笔高亮(mark)，原生自带背景色
2. 上标与下标 (化学党的福音)

专门用来写公式或者引用标注。

<!-- sub = subscript (下标) -->
三硝基猫猫酚: C<sub>6</sub>H<sub>3</sub>N<sub>3</sub>O<sub>7</sub>

<!-- sup = superscript (上标) -->
勾股定理: a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup>
化学式： C6H3N3O7
数学式： a2 + b2 = c2
引用： 这是一个引用[1]
3. 标题与段落 (文章骨架)

网页的结构就是靠这些撑起来的。

<h1>我是最大的标题 (网页一般只用一个)</h1>
<h2>我是二级标题</h2>
<h3>我是三级标题...直到 h6</h3>
<p>我是一个段落。段落之间会有天然的间距。</p>
<hr /> <!-- 水平分割线 -->
<br /> <!-- 强制换行 -->

h1 标题

h2 标题

h3 标题

这是第一段话。

4. 列表 (Lists)

用来展示清单、目录或步骤。

<!-- ul: Unordered List (无序列表 - 黑点) -->
<ul>
  <li>猫猫</li>
  <li>狗狗</li>
</ul>

<!-- ol: Ordered List (有序列表 - 数字) -->
<ol>
  <li>第一步：打开冰箱</li>
  <li>第二步：把大象放进去</li>
</ol>

5. 两个最重要的盒子 (div vs span)

这是新手最容易混淆的概念。

<!-- div: 块级元素 (Block) -->
<!-- 特点：独占一行，不管内容多少，都会强制换行 -->
<div style="background:#eee">我是 div，我霸占了一整行</div>

<!-- span: 行内元素 (Inline) -->
<!-- 特点：内容多少就占多少地，可以和其他字挤在一行 -->
我在一段文字里 <span style="color:red">偷偷插入一个 span</span> 改变颜色。
我是 div 1
我是 div 2 (看到没，我也换行了)

这是一段话，span 只是一个小包装袋，不会打断文字。

6. 媒体与链接
<!-- a: Anchor (链接) -->
<!-- target="_blank" 表示在新窗口打开 -->
<a href="https://bilibili.com" target="_blank">去 B 站</a>

<!-- img: Image (图片) - 自闭合标签 -->
<img src="avatar.png" alt="头像" width="50" />
